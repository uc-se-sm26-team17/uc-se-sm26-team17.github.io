About the Project

This real-time messaging application delivers a complete communication platform featuring public channels, private 1-on-1 direct messages, and dynamic group chats. Built with security and engagement in mind, it features custom authentication, live online presence tracking, and real-time typing indicators. Users can easily manage custom group memberships or update their account details—including username, email, and password—directly through an integrated settings panel.
