About the Project

This project is a real-time messaging application designed with a public chat and private 1-on-1 and groupchat capabilities. Users can login with unique usernames that identify to other users who they are when they send messages and as they type messages out. All connected users can be viewed at once so that users know who is able to view and send messages while they are connected themself.
